# Night Core V1

[English](README.md) | **Русский**

Night Core V1 — универсальное ядро приватного сервера Geometry Dash, основанное на Cvolton-совместимом протоколе и переработанное в набор повторно используемых PHP-модулей. Ядро рассчитано на PHP 8.1+ и MySQL/MariaDB, сохраняет игровой wire-format и добавляет собственные подсистемы аккаунтов, персонала, Event Level и локальных медиа.

## Текущая архитектура

- тонкие публичные endpoint-файлы в `public/`;
- прикладная, протокольная, защитная и доменная логика в `src/`;
- подготовленные PDO-запросы и проверяемые внутренние имена таблиц;
- последовательные SQL-миграции в `migrations/`;
- единая авторизация legacy GJP/GJP2;
- локальные настройки установки через `.env`, `config/media.php` и `config2.php`;
- CLI-установка, миграции, диагностика и обработчик удаления аккаунтов;
- тесты без БД и интеграционные тесты MariaDB.

Точкой совместимости остаётся `Cvolton/GMDprivateServer` на commit `719dfe36c622a54c8162b07967241fce79b2497c`. Night Core является изменённым/производным GPLv3-проектом; см. `LICENSE` и `docs/UPSTREAM.md`.

## Реализованные функции

- регистрация и вход через корневые и `/accounts/`-совместимые пути;
- endpoint-ы аккаунтов, профилей, уровней, социальных функций, прогресса, комментариев и модерации;
- совместимость со штатной панелью оценки уровней Geometry Dash;
- RBAC-роли с детальными правами и стандартными бейджами модераторов;
- внутриигровые команды оценки, demon difficulty, банов аккаунта и лидерборда;
- очередь и принудительная активация Daily/Weekly;
- протокол Event Level Geometry Dash 2.207, timely-download и журнал получения наград;
- поиск песен Newgrounds/Boomlings и локальное кеширование;
- локальная MP3-библиотека и отдельная Ogg SFX-библиотека;
- жизненный цикл аккаунта с опциональным запланированным обезличиванием.

## Веб-интерфейсы

### `/dashboard.php`

Основной публичный дешборд содержит две вкладки:

- **Songs / SFX** — публичные библиотеки только для просмотра; формы загрузки появляются после входа активным и незаблокированным аккаунтом GDPS;
- **Daily / Weekly / Event** — текущие ротации в формате `название / автор / #ID`.

Окно аккаунта поддерживает регистрацию, вход, настройку повторного подтверждения паролем, планирование удаления при включённой функции и выход. `/mediaAdmin.php` оставлен как совместимый редирект на `/dashboard.php`.

### `/staffAdmin.php`

Аккаунты с `staff.manage` могут создавать роли, выбирать детальные права, настраивать стандартные бейджи Geometry Dash, назначать персонал и снимать назначения. Bootstrap-владельцы из `CORE_ADMIN_ACCOUNT_IDS` всегда сохраняют все права и не могут быть понижены через панель.

### `/eventAdmin.php`

Уполномоченные владельцы и сотрудники просматривают Event-записи, выдачи наград и аудит, а также завершают или отменяют активные/запланированные события. Создание Event и изменение ротаций выполняются защищёнными командами в комментариях Geometry Dash.

## Единый модуль веб-защиты

`src/Web/Security/` — общий защитный слой для трёх браузерных панелей. Он обеспечивает:

- строгие cookie-only PHP-сессии;
- смену ID сессии после входа и выхода;
- настраиваемый тайм-аут бездействия и абсолютный срок;
- проверку активности, бана и наступившего удаления на каждом запросе;
- привязку сессии к отпечатку браузера;
- отдельные CSRF-токены каждой панели;
- Content Security Policy с nonce для script/style-блоков;
- запрет iframe, MIME-sniffing, защитные referrer/permissions/cross-origin заголовки;
- запрет кеширования и индексации приватных панелей;
- общие хешированные идентификаторы для ограничения входов в staff/Event.

Подробности: `docs/ru/WEB_SECURITY.md`.

## Приватная конфигурация

### `config2.php`

Скопируй пример в корень проекта:

```bash
cp config2.example.php config2.php
```

Файл управляет:

```php
return [
    'account_deletion_enabled' => true,
    'session_idle_timeout_seconds' => 1800,
    'session_absolute_timeout_seconds' => 28800,
];
```

Значение тайм-аута `0` отключает соответствующее ограничение. Если оба значения равны `0`, сессия действует до выхода или другой защитной причины. `config2.php` исключён из Git. См. `docs/ru/CONFIG2.md`.

### `config/media.php`

Скопируй `config/media.php.example`, чтобы настроить авторизованные публичные загрузки, размеры файлов и приватные ограничения загрузчика. Дешборд не раскрывает интервалы ожидания и квоты. См. `docs/ru/MEDIA_DASHBOARD.md`.

### `.env`

Начни с `.env.production.example`. Пароли БД, ключи хеширования и `CORE_ADMIN_ACCOUNT_IDS` должны оставаться приватными. Production `.env` нельзя коммитить.

## Команды продакшена

```bash
php bin/nightcore install
php bin/nightcore migrate
php bin/nightcore doctor
```

Перед открытием трафика `doctor` не должен показывать критических ошибок, а `/ready.php` должен отвечать HTTP 200 и `ready`.

При включённом удалении аккаунтов запускай обработчик периодически:

```bash
php bin/nightcore accounts:purge-due
```

Пример hourly cron:

```cron
17 * * * * cd /var/www/nightcore && /usr/bin/php bin/nightcore accounts:purge-due >/dev/null 2>&1
```

## Локальная проверка

```bash
docker compose up --build -d
docker compose exec web php bin/nightcore migrate
docker compose exec web php bin/nightcore doctor
docker compose exec web php bin/nightcore self-test
```

CI дополнительно проверяет синтаксис, модуль веб-защиты, wire-format комментариев, MariaDB-интеграцию, песни, медиа-дешборд, безопасность/удаление аккаунтов и Event rewards.

## Границы совместимости

- Основная цель Night Core — Geometry Dash 2.2/2.207; ядро не заявляет полное покрытие всех старых клиентов Cvolton.
- Серверная загрузка, хранение и скачивание SFX готовы, но discovery-путь неизменённого stock-клиента ещё требует окончательной проверки.
- Cloudflare, firewall/Nginx, PHP-FPM-лимиты и резервные копии остаются задачами инфраструктуры; прикладные лимиты не являются DDoS-защитой.
