# Night Core deployment files

These files are operator examples and are not loaded automatically by Night Core.

- `nginx/nightcore.conf.example` - Nginx virtual host with `public/` as document root.
- `cron/nightcore.cron.example` - hourly account-deletion worker.

Read:

- `docs/DEPLOYMENT.md`;
- `docs/UPDATING.md`;
- `docs/BACKUP_AND_RECOVERY.md`;
- `docs/DEPLOYMENT_CHECKLIST.md`.

Russian versions are in `docs/ru/`.
