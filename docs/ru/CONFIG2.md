# Приватная политика `config2.php`

`config2.php` объединяет локальные настройки удаления аккаунтов и времени жизни браузерных сессий.

## Расположение и создание

Файл находится в корне проекта:

```text
/var/www/nightcore/config2.php
```

Создай его из отслеживаемого примера:

```bash
cd /var/www/nightcore
cp config2.example.php config2.php
php -l config2.php
```

Рабочий файл исключён из Git и не заменяется обычным `git pull`.

## Поддерживаемые значения

```php
<?php

declare(strict_types=1);

return [
    'account_deletion_enabled' => true,
    'session_idle_timeout_seconds' => 1800,
    'session_absolute_timeout_seconds' => 28800,
];
```

### `account_deletion_enabled`

- `true` — пользователи могут планировать/отменять удаление, а worker обрабатывает наступившие сроки.
- `false` — новые запросы отклоняются, наступившие даты не блокируют вход, worker не обезличивает аккаунты.

Существующие даты остаются в базе во время паузы. После повторного включения они возобновляются; уже просроченные запросы могут быть обработаны следующим запуском worker.

### `session_idle_timeout_seconds`

Максимальное бездействие для dashboard, staff и Event. `0` отключает завершение по бездействию.

### `session_absolute_timeout_seconds`

Максимальный общий срок от момента входа. `0` отключает абсолютный срок.

Если оба значения равны `0`, отключается только автоматическое завершение по времени. Выход, деактивация/бан аккаунта, наступившее удаление, несовпадение отпечатка браузера или отозванное право панели всё равно прекращают доступ.

## Проверка и fallback

Boolean принимает PHP `true`/`false`, целые `0`/`1` и обычные boolean-строки. Тайм-аут должен быть неотрицательным целым числом не больше 315 360 000 секунд.

При отсутствии файла используются значения:

```text
удаление аккаунтов: включено
тайм-аут бездействия: 1800 секунд
абсолютный срок: 28800 секунд
```

Если файл возвращает неверные данные или вызывает runtime-ошибку, Night Core записывает проблему в лог и использует безопасные значения по умолчанию, не создавая намеренно HTTP 500. Синтаксическая ошибка PHP всё равно может остановить загрузку файла, поэтому после редактирования всегда запускай `php -l config2.php`.

Старый `config/account.php` читается только при отсутствии `config2.php`.

## Применение изменений

Обычно файл читается на каждом запросе. После production-изменения рекомендуется перезапустить PHP-FPM, чтобы opcode cache точно не удерживал старую версию:

```bash
sudo systemctl restart php8.5-fpm
sudo systemctl is-active php8.5-fpm
```
