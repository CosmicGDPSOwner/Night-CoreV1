# Панель аккаунта в медиа-дешборде

`/mediaAdmin.php` остаётся публичной библиотекой песен и SFX. Для загрузки файлов требуется аккаунт GDPS.

В правом верхнем углу находится кнопка **Sign in / Register**. Она открывает модальное окно с двумя вкладками:

- вход существующим аккаунтом GDPS;
- регистрация нового обычного аккаунта GDPS.

Регистрация использует тот же `AccountService`, хеширование пароля, настройку `ACCOUNT_PREACTIVATE` и таблицу аккаунтов, что и игровой `registerGJAccount.php`. Попытки регистрации ограничиваются по HMAC-хешам точного IP и подсети; исходные IP-адреса не сохраняются.

Рекомендуемые production-настройки:

```env
REGISTRATION_MAX_PER_IP=2
REGISTRATION_MAX_PER_SUBNET=10
REGISTRATION_WINDOW_SECONDS=86400
REGISTRATION_IP_HASH_KEY=длинный_случайный_секрет
```

После успешной регистрации предварительно активированный аккаунт сразу получает защищённую сессию дешборда. Если `ACCOUNT_PREACTIVATE=0`, аккаунт создаётся, но войти можно только после активации.
