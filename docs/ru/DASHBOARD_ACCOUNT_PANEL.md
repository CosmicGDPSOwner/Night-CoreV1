# Панель аккаунта в дешборде

`/dashboard.php` — основной публичный дешборд песен и SFX. `/mediaAdmin.php` оставлен только как совместимый редирект.

Кнопка **Sign in / Register** в правом верхнем углу открывает окно аккаунта, в котором доступны:

- вход существующим аккаунтом GDPS;
- регистрация через тот же сервис аккаунтов, хеширование паролей и правила активации, что используются игрой;
- профиль вошедшего пользователя и выход;
- планирование удаления аккаунта.

Защита загрузок и регистрации продолжает работать на сервере. Дешборд намеренно не публикует квоты соединения, интервалы ожидания, пороги регистрации и сведения об идентификаторах, полученных из сетевых адресов.

Для планирования удаления требуется текущий пароль и точное имя аккаунта. Пользователь может выбрать 7, 14, 30, 60 или 90 дней и отменить запрос до наступления срока. После наступления срока фоновая команда отключает аккаунт и обезличивает имя, почту и данные входа. Опубликованные уровни сохраняются под именем удалённого пользователя. Bootstrap-администраторы из `CORE_ADMIN_ACCOUNT_IDS` не могут запланировать удаление через публичный дешборд.

Команду обработки удаления следует запускать периодически, например раз в час:

```bash
php /var/www/nightcore/bin/nightcore accounts:purge-due
```

Пример задания cron:

```cron
17 * * * * cd /var/www/nightcore && /usr/bin/php bin/nightcore accounts:purge-due >/dev/null 2>&1
```

Все операции с аккаунтами и дешбордом используют параметризованные PDO-запросы. Пользовательские данные передаются как параметры и не объединяются со строкой SQL.

Рекомендуемые параметры защиты регистрации хранятся только в `.env`:

```env
REGISTRATION_MAX_PER_IP=2
REGISTRATION_MAX_PER_SUBNET=10
REGISTRATION_WINDOW_SECONDS=86400
REGISTRATION_IP_HASH_KEY=длинный_случайный_секрет
```
