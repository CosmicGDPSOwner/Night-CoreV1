# Daily, Weekly и Event Levels

Night Core хранит Daily, Weekly и Event в собственных таблицах ротаций и реализует timely-протокол оригинального Geometry Dash.

## Публичный просмотр

`/dashboard.php?tab=rotations` показывает активные Daily, Weekly и Event в формате:

```text
название / автор / #ID
```

Вкладка только для просмотра и не требует входа.

## Команды Geometry Dash

Уполномоченный персонал может использовать команды в комментариях уровня:

- `!daily` / `!weekly` — поставить уровень в очередь на обычную UTC-границу;
- `!daily now` или `!daily force` — активировать сразу до следующей UTC-полуночи;
- `!weekly now` или `!weekly force` — активировать сразу до следующего понедельника 00:00 UTC;
- `!event ...` — создать Event из комментируемого уровня;
- `!eventchange ...` — изменить текущий Event по параметрам команды;
- `!eventset ...` — явно задать параметры Event.

Параметры Event проверяют старт, длительность и снимок награды. Для stock-клиента используются только типы, корректно реализованные в ответе 2.207: diamonds, orbs, keys и gold keys.

## Event-протокол и claims

Реализованы:

- Event timely ID и специальный ID `-3` в `downloadGJLevel22.php`;
- timely-поле `41` и timely hash;
- подписанный ответ награды Event 2.207;
- поиск текущего Event через type `23`;
- уникальный журнал получения по паре Event + аккаунт;
- снимки наград и Event audit.

Оригинальный клиент применяет поддерживаемую награду локально из подписанного Event-ответа. Night Core фиксирует серверный claim и не выдаёт этот журнал за замену локального начисления клиентом.

## Event-панель

`/eventAdmin.php` — защищённая страница владельца/персонала с Event-правами. Она показывает события, claims и аудит, а также позволяет завершить или отменить активный/запланированный Event при наличии нужного права.

Панель использует единый web-security модуль и опциональное повторное подтверждение паролем. Создание и постановка в расписание остаются командными действиями.
