# Медиа-библиотека дешборда

`/dashboard.php?tab=media` — основная публичная страница песен и SFX. `/mediaAdmin.php` оставлен только как совместимый редирект.

## Публичная и авторизованная части

Без входа доступны:

- ID, название, автор, размер и URL локальных MP3-песен;
- ID, название, размер и URL локальных Ogg SFX;
- допустимый размер одного файла.

Загрузка доступна только после входа активным аккаунтом GDPS, который не заблокирован и не достиг срока удаления. Используется та же база аккаунтов и паролей, что и в Geometry Dash. Открытый пароль в PHP-сессии не хранится.

Дешборд намеренно не показывает интервалы ожидания, сетевые/глобальные квоты, пороги регистрации и идентификаторы, полученные из адресов. При срабатывании лимитера возвращается общее сообщение о временной недоступности.

## Приватная политика медиа

Один раз скопируй пример:

```bash
cp config/media.php.example config/media.php
```

`config/media.php` исключён из Git. Пример:

```php
<?php
return [
    'public_uploads' => true,
    'song_max_mib' => 25,
    'sfx_max_mib' => 10,
    'upload_cooldown_seconds' => 30,
    'uploads_per_hour_per_ip' => 10,
    'global_uploads_per_hour' => 200,
    'minimum_free_space_mib' => 512,
];
```

Редактировать файл должен только владелец сервера. При `public_uploads=false` библиотеки остаются видимыми, а формы загрузки скрываются и отклоняются сервером.

## Серверная защита

Перед сохранением Night Core проверяет авторизацию, CSRF, состояние HTTP-upload, формат, размер, резервирование лимита и свободное место. Состояние ограничений хранится в MariaDB, сетевые адреса не записываются открытым текстом.

Эти проверки уменьшают злоупотребления, но не заменяют Cloudflare, firewall origin-сервера, лимиты Nginx/PHP и DDoS-защиту.

## Хранилище

Рекомендуемые production-пути:

```env
CUSTOM_SONG_STORAGE_PATH=/var/lib/nightcore/songs
CUSTOM_SFX_STORAGE_PATH=/var/lib/nightcore/sfx
```

Пользователю PHP-FPM нужны права чтения/записи. Хранилище следует держать вне `public/`.

## Граница совместимости SFX

Серверная Ogg-библиотека, range-download и сохранение `sfxIDs` реализованы. Неизменённый Geometry Dash использует собственный механизм discovery/CDN, поэтому успешное скачивание через браузер не доказывает stock-client discovery.
