# Публичный медиа-дашборд

Night Core использует `/mediaAdmin.php` как публичную библиотеку/загрузчик медиа, когда владелец сервера включает публичные загрузки в приватном локальном PHP-файле настроек.

## Что доступно пользователю

Страница поддерживает:

- загрузку MP3-песен через существующую локальную библиотеку;
- загрузку SFX в Ogg (`.ogg`) через отдельную библиотеку эффектов;
- просмотр списков песен/SFX с ID, размером и download URL;
- только просмотр текущих лимитов одного файла и антиспам-политики;
- CSRF-защиту браузерных форм загрузки.

На этой странице нет входа по admin token. Также публичному пользователю не выдаются действия удаления файлов или изменения лимитов.

Старый `/songAdmin.php` остаётся защищённым токеном для совместимости и приватного управления песнями владельцем.

## Приватные настройки владельца в PHP

Один раз скопируйте пример:

```bash
cp config/media.php.example config/media.php
```

`config/media.php` исключён из Git, поэтому обычный `git pull` не перезаписывает локальные настройки владельца. Пример production-конфигурации:

```php
<?php
return [
    'public_uploads' => true,
    'song_max_mib' => 25,
    'sfx_max_mib' => 10,
    'upload_cooldown_seconds' => 30,
    'uploads_per_hour_per_ip' => 10,
    'global_uploads_per_hour' => 200,
    'minimum_free_space_mib' => 512,
];
```

Редактировать этот файл должен только владелец сервера. Для обычного Linux + Nginx + PHP-FPM:

```bash
chown root:www-data config/media.php
chmod 0640 config/media.php
```

PHP нужен доступ на чтение; пользователям сайта доступ на запись не нужен.

`public_uploads=false` оставляет библиотеку доступной для просмотра, но скрывает формы и отклоняет попытки загрузки. Если `config/media.php` отсутствует, публичная загрузка по умолчанию выключена.

## Защита от спама и заполнения диска

Night Core применяет защиту до записи файла в постоянное media-хранилище:

- `upload_cooldown_seconds` — минимальная пауза между успешными попытками резервирования загрузки с одного IP;
- `uploads_per_hour_per_ip` — максимум загрузок с одного IP за часовое окно;
- `global_uploads_per_hour` — общий максимум загрузок через публичный uploader за часовое окно;
- `minimum_free_space_mib` — резерв свободного места, ниже которого новые загрузки автоматически приостанавливаются.

Состояние rate limit хранится в MariaDB в `core_media_upload_rate_limits`. IP не сохраняется открытым текстом: Night Core использует SHA-256 hash адреса как ключ лимитера.

Значение `0` отключает соответствующий cooldown/часовой лимит. Для `minimum_free_space_mib` используется положительное значение.

При `TRUST_PROXY_HEADERS=0` источником IP является `REMOTE_ADDR`. Заголовок `X-Forwarded-For` используется только когда администратор явно включил `TRUST_PROXY_HEADERS=1`; origin при таком режиме должен быть закрыт от обхода доверенного reverse proxy.

## Лимиты размера файлов

`song_max_mib` и `sfx_max_mib` задаются целым числом MiB. Night Core применяет эти значения при сохранении файлов. Если один из лимитов не указан в приватном PHP-файле, используются fallback-значения окружения:

```env
CUSTOM_SONG_MAX_BYTES=26214400
CUSTOM_SFX_MAX_BYTES=10485760
```

Публичная страница может только показать лимиты, но не изменить их.

Лимит Night Core всё равно ограничен инфраструктурой. `upload_max_filesize`, `post_max_size`, Nginx `client_max_body_size`, Apache, reverse proxy и ограничения хостинга тоже должны пропускать запрос. Уменьшение значения в `config/media.php` применяется сразу и не требует перезапуска PHP-FPM.

## Хранилища

Рекомендуемые production-пути:

```env
CUSTOM_SONG_STORAGE_PATH=/var/lib/nightcore/songs
CUSTOM_SFX_STORAGE_PATH=/var/lib/nightcore/sfx
```

Оба каталога должны находиться вне `public/` и быть доступны на запись пользователю PHP/web-сервера.

```bash
mkdir -p /var/lib/nightcore/songs /var/lib/nightcore/sfx
chown -R www-data:www-data /var/lib/nightcore/songs /var/lib/nightcore/sfx
chmod 0755 /var/lib/nightcore/songs /var/lib/nightcore/sfx
```

При включённых публичных загрузках `php bin/nightcore doctor` требует, чтобы оба хранилища были доступны на запись.

## Библиотека SFX

SFX записываются в `core_local_sfx` и раздаются через `/downloadCustomSfx.php?sfxID=<ID>`. Загрузчик принимает Ogg и проверяет заголовок контейнера `OggS` перед сохранением.

Диапазон локальных SFX по умолчанию:

```env
CUSTOM_SFX_ID_MIN=2000000
CUSTOM_SFX_ID_MAX=8999999
```

Пространство ID эффектов отдельное от Song ID. Поэтому одинаковое число может существовать одновременно как Song ID и как SFX ID без конфликта в базе.

### Граница совместимости с оригинальным Geometry Dash 2.2

Серверная часть SFX уже реализована: загрузка, хранение, byte-range скачивание и сохранение `sfxIDs` в уровнях. Но оригинальный Geometry Dash получает SFX не так, как кастомные песни: для песни сервер отдаёт явный download URL в метаданных, а SFX относятся к отдельной audio-library/CDN-механике игры. Точный путь обнаружения/запроса локальных SFX оригинальным клиентом остаётся отдельной задачей совместимости.

Успешное скачивание `.ogg` браузером само по себе не доказывает, что оригинальная игра запросит тот же URL.

## Миграции базы

`0010_media_dashboard.sql` создаёт SFX/media-таблицы, а `0011_public_media_rate_limits.sql` добавляет состояние защиты публичного uploader.

Размещайте только аудио, которое вы имеете право хранить и распространять.
