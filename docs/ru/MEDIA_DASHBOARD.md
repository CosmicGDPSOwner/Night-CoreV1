# Медиа-дашборд владельца

Night Core содержит небольшой закрытый дашборд `/mediaAdmin.php`, через который владелец может управлять серверным аудио без ручного редактирования базы данных.

## Что уже есть

Дашборд поддерживает:

- загрузку MP3 через существующую локальную библиотеку песен;
- загрузку SFX в Ogg (`.ogg`) через отдельную локальную библиотеку эффектов;
- просмотр и удаление песен/SFX;
- отдельный лимит размера одного файла для песен и для SFX;
- сохранение изменённых лимитов в MariaDB, поэтому для уменьшения лимита не нужно редактировать `.env` или перезапускать PHP-FPM;
- сессию после входа и CSRF-защиту всех изменяющих операций.

Старый `/songAdmin.php` остаётся доступным для совместимости. Основным интерфейсом владельца дальше считается `/mediaAdmin.php`.

## Авторизация

Можно задать отдельный токен дашборда:

```env
MEDIA_ADMIN_TOKEN=CHANGE_ME_LONG_RANDOM_SECRET
```

Если `MEDIA_ADMIN_TOKEN` пустой, Night Core использует `CUSTOM_SONG_ADMIN_TOKEN`. Поэтому существующий сервер можно перевести на новый дашборд без немедленной смены текущего секрета загрузчика песен.

Дашборд не должен быть публичной панелью. На тестовом сервере без HTTPS открывайте его через SSH-туннель, чтобы токен не передавался открытым HTTP. Для production нужен HTTPS.

## Хранилища

Рекомендуемые production-пути:

```env
CUSTOM_SONG_STORAGE_PATH=/var/lib/nightcore/songs
CUSTOM_SFX_STORAGE_PATH=/var/lib/nightcore/sfx
```

Оба каталога должны находиться вне `public/` и быть доступны на запись пользователю PHP/web-сервера.

Пример для Linux:

```bash
mkdir -p /var/lib/nightcore/songs /var/lib/nightcore/sfx
chown -R www-data:www-data /var/lib/nightcore/songs /var/lib/nightcore/sfx
chmod 0755 /var/lib/nightcore/songs /var/lib/nightcore/sfx
```

`php bin/nightcore doctor` проверяет оба хранилища, когда медиа-дашборд включён или когда в базе уже есть локальные медиафайлы.

## Лимиты загрузки

Значения по умолчанию из окружения:

```env
CUSTOM_SONG_MAX_BYTES=26214400
CUSTOM_SFX_MAX_BYTES=10485760
```

В интерфейсе лимиты задаются в MiB. Например, при смене лимита песен с `25` на `10` Night Core сохраняет runtime-значение `10 MiB` в `core_media_settings`. Следующая загрузка уже будет ограничена 10 MiB.

Это лимит самого Night Core, а не замена лимитов инфраструктуры. `upload_max_filesize`, `post_max_size`, Nginx `client_max_body_size`, Apache, reverse proxy или ограничения хостинга тоже должны пропускать запрос. Уменьшение лимита в дашборде применяется сразу. Для увеличения выше лимита PHP/Nginx придётся отдельно поднять соответствующий серверный предел.

## Библиотека SFX

SFX записываются в `core_local_sfx` и раздаются через `/downloadCustomSfx.php?sfxID=<ID>`. Сейчас загрузчик принимает Ogg и проверяет заголовок контейнера `OggS` перед сохранением.

Диапазон локальных SFX по умолчанию:

```env
CUSTOM_SFX_ID_MIN=2000000
CUSTOM_SFX_ID_MAX=8999999
```

Пространство ID эффектов отдельное от Song ID. Поэтому одинаковое число может существовать одновременно как Song ID и как SFX ID без конфликта в базе.

### Граница совместимости с оригинальным Geometry Dash 2.2

Серверная часть SFX уже реализована: загрузка, хранение, byte-range скачивание и сохранение `sfxIDs` в уровнях. Но оригинальный Geometry Dash получает SFX не так, как кастомные песни. Для песни сервер отдаёт игре явный download URL в метаданных, а SFX относятся к отдельной audio-library/CDN-механике игры.

Поэтому маршрут локальных SFX ещё нужно проверить именно через наш GDPS Switcher и оригинальный клиент, прежде чем считать прозрачную загрузку серверных SFX полностью подтверждённой.

Успешное скачивание `.ogg` браузером само по себе не доказывает, что оригинальная игра запросит тот же URL.

## Миграция базы

Миграция `0010_media_dashboard.sql` создаёт:

- `core_media_settings` — runtime-настройки дашборда;
- `core_local_sfx` — метаданные локальных SFX.

Применение:

```bash
php bin/nightcore migrate
php bin/nightcore doctor
```

## Граница безопасности

Это интерфейс владельца, а не публичный загрузчик для игроков. Анонимную загрузку включать не следует. Публичная система отправки аудио должна быть отдельным потоком с авторизацией аккаунта, модерацией, квотами и защитой от злоупотреблений.

Загружайте только аудио, которое вы имеете право хранить и распространять.
