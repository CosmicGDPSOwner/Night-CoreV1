# Роли и права персонала

Night Core управляет персоналом отдельно в каждой установке. У каждого GDPS свои роли, назначения и оформление, хранящиеся в его собственной базе данных.

## Начальный владелец

В `CORE_ADMIN_ACCOUNT_IDS` указываются числовые ID аккаунтов Night Core через запятую. Эти аккаунты считаются владельцами и всегда имеют все права. Они не хранятся в редактируемой таблице назначений и не могут быть понижены через dashboard.

## Dashboard

Страница управления: `/staffAdmin.php`.

Вход выполняется обычными логином и паролем аккаунта Night Core, у которого есть право `staff.manage`. Аккаунты из `CORE_ADMIN_ACCOUNT_IDS` имеют его автоматически.

Dashboard позволяет:

- создавать произвольные роли;
- редактировать права каждой роли;
- назначать роль по username или account ID;
- выбирать стандартный бейдж Geometry Dash: нет / moderator / elder;
- задавать собственный текст бейджа для web/dashboard;
- задавать цвет бейджа, комментария и имени для интерфейсов Night Core;
- снимать роли и удалять роли.

Страница принимает пароль аккаунта и меняет привилегии, поэтому в продакшене её нужно открывать только через HTTPS. На тестовом VPS без HTTPS безопаснее использовать локальный SSH-туннель, а не вводить пароль через публичный HTTP.

## Права

Права хранятся отдельно от ролей в `core_staff_role_permissions`. Уже предусмотрены разрешения на suggest/rate/feature/epic/demon, модерацию комментариев, управление пользователями, просмотр жалоб, управление локальными медиа и `staff.manage`.

Старые записи `core_moderator_roles` пока остаются fallback-механизмом для совместимости со старыми установками.

## Оформление комментариев в оригинальной Geometry Dash

Для ответов комментариев 2.1+ (`binaryVersion > 31`) Night Core отдаёт стандартные поля Geometry Dash:

- поле `11` — уровень moderator badge (`0`, `1` или `2`);
- поле `12` — RGB-цвет комментария, если бейдж включён.

Формат соответствует закреплённой Cvolton-совместимости. `badgeText`, `badgeColor` и `usernameColor` остаются расширенными метаданными Night Core: оригинальная Geometry Dash понимает только стандартный числовой moderator badge и RGB-цвет комментария.
