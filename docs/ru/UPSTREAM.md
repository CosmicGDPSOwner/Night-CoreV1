# Upstream и лицензирование

Night Core V1 использует **Cvolton/GMDprivateServer** как эталон совместимости и реализации.

[English version](../UPSTREAM.md)

Закреплённая upstream-ревизия:

```text
719dfe36c622a54c8162b07967241fce79b2497c
```

Репозиторий:

```text
Cvolton/GMDprivateServer
```

Upstream-проект распространяется по GNU General Public License version 3. Night Core V1 должен сохранять применимые условия GPL для кода, производного от этого проекта или скопированного из него.

## Политика для импортированного кода

- Указывать upstream-файл и ревизию, когда код копируется или существенно адаптируется.
- По возможности явно отмечать изменения Night Core.
- Не удалять upstream copyright/license notices.
- Держать NightGDPS-специфичные модули отдельно, когда это возможно.
- Никогда не переносить в репозиторий production secrets, credentials панели хостинга или приватную конфигурацию.

Цель проекта — не присваивать авторство исходной реализации Cvolton, а развивать универсальное GDPS-ядро на явно документированной upstream-базе.
